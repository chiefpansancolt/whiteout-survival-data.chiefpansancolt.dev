# whiteout-survival-data.chiefpansancolt.dev

Documentation site for the [whiteout-survival-data](https://github.com/chiefpansancolt/whiteout-survival-data)
npm package, built with Next.js + [Markdoc](https://markdoc.dev).

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
```
